# UI设计-写作模块

## 1. 设计目标

写作模块的UI设计旨在提供一个专注、高效的写作环境，同时确保用户能够方便地获取AI反馈和学习建议。设计遵循以下原则：

- **专注写作体验**：提供简洁无干扰的写作区域，帮助用户集中注意力
- **即时反馈机制**：实时显示字数统计和基本语法检查
- **清晰的任务指导**：明确展示写作题目和要求
- **结构化的评分反馈**：以可视化方式展示AI评分结果和改进建议
- **响应式适配**：在不同设备上提供一致的写作体验

## 2. 页面结构

### 2.1 核心功能模块

| 功能模块 | 描述 |
| --------- | ------ |
| 题目展示区 | 显示写作题目、类型（Task 1/Task 2）、要求和时间限制 |
| 写作输入区 | 提供富文本编辑器，支持基本格式和语法检查 |
| 字数统计 | 实时显示当前字数和目标字数 |
| 工具栏 | 提供保存、提交、格式调整等功能按钮 |
| AI反馈区 | 展示语法错误、词汇建议、评分和改进意见 |
| 历史记录 | 显示用户过往写作练习和评分记录 |

### 2.2 页面布局

```
|                                   |

|                                   |
+-----------------------------------+

+-----------------------------------+
```

在平板上保持垂直布局，但增加更多的留白和更宽的写作区域：

```

```

## 3. 视觉设计

### 3.1 色彩方案

| 元素 | 颜色 | 用途 |
|------|------|------|
| 主色调 | #4A6CF7 | 按钮、重要功能标识 |
| 辅助色 | #F7B955 | 字数统计、时间提醒 |
| 背景色 | #FFFFFF | 写作区域背景 |
| 文本色 | #333333 | 主要文本内容 |
| 边框色 | #E0E0E0 | 输入框、分隔线 |
| 错误色 | #F44336 | 语法错误标记 |
| 成功色 | #4CAF50 | 字数达标提示 |

### 3.2 排版设计

| 元素 | 字体 | 字号 | 行高 | 颜色 |
| ------ | ------ | ------ | ------ | ------ |
| 模块标题 | Inter-Semibold | 20px | 1.4 | #333333 |
| 题目标题 | Inter-Bold | 18px | 1.5 | #333333 |
| 题目内容 | Inter-Regular | 16px | 1.6 | #555555 |
| 写作文本 | Inter-Regular | 16px | 1.7 | #333333 |
| 字数统计 | Inter-Medium | 14px | 1.2 | #F7B955 |
| 按钮文本 | Inter-Medium | 14px | 1.2 | #FFFFFF |

### 3.3 组件样式

#### 3.3.1 写作输入框

- 宽度：
  - 移动端：100% - 32px
  - 平板：100% - 48px
  - 网页端：800px 或 100% - 64px
- 高度：
  - 移动端：300px
  - 平板：400px
  - 网页端：500px
- 内边距：16px
- 边框：1px solid #E0E0E0，圆角 8px
- 背景色：#FFFFFF
- 阴影：无，保持简洁专注

#### 3.3.2 字数统计组件

- 显示当前字数/目标字数
- 当字数达到 80% 目标时，颜色变为 #4CAF50（成功色）
- 当时间剩余不足 10 分钟时，添加警告动画效果

#### 3.3.3 AI反馈卡片

- 背景色：#F5F5F5
- 内边距：16px
- 边框：1px solid #E0E0E0，圆角 8px
- 错误提示：使用红色波浪线标记文本中的语法错误
- 词汇建议：使用蓝色高亮显示可替换的词汇

## 4. 交互设计

### 4.1 核心交互流程

#### 4.1.1 写作练习流程

```
1. 用户选择写作任务类型（Task 1/Task 2）
2. 系统展示题目和要求
3. 用户开始写作，实时显示字数统计
4. AI实时提供语法检查和词汇建议
5. 用户可保存草稿或提交练习
6. 提交后，系统生成详细的评分报告
```

#### 4.1.2 语法检查交互

- 实时检查文本中的语法错误
- 错误位置显示红色波浪线
- 点击错误位置，显示具体的错误原因和修正建议
- 提供一键修正功能

### 4.2 表单验证

| 表单元素 | 验证规则 | 错误提示 |
| ---------- | ---------- | ---------- |
| 写作内容 | 不能为空 | "请输入你的作文内容" |
| 字数限制 | Task 1: ≥150词<br>Task 2: ≥250词 | "作文字数不足要求" |

## 5. 响应式设计

### 5.1 移动端适配（320-767px）

- 垂直堆叠所有内容
- 简化工具栏，只保留核心功能
- 写作区域高度自适应屏幕空间
- 图表/图片自适应宽度

### 5.2 平板适配（768-1023px）

- 增加写作区域宽度
- 显示完整的工具栏
- 图表/图片以合适比例展示

### 5.3 网页端适配（1024px+）

- 采用左右分栏布局
- 提供更宽的写作区域
- 实时显示完整的AI反馈
- 支持多窗口操作

## 7. 评分报告页面

### 7.1 页面结构

| 区域 | 内容 |
| ------ | ------ |
| 总分区域 | 显示总体得分（1-9分） |
| 分项评分 | 展示四个评分维度（任务完成度、连贯性、词汇、语法） |
| 优势分析 | 指出作文中的亮点 |
| 改进建议 | 提供具体的提升方向 |
| 示例修改 | 展示优秀的修改示例 |
| 重写功能 | 允许用户基于反馈重新写作 |

### 7.2 评分报告原型

```
+-----------------------------------+
| ← | 写作评分报告                  |
+-----------------------------------+
|  🎯 总分：6.5分                   |
|                                   |
|  ⭐ 分项评分：                     |
|  - 任务完成度：7.0                |
|  - 连贯性与衔接：6.5              |
|  - 词汇丰富度：6.0                |
|  - 语法准确性：6.5                |
|                                   |
+-----------------------------------+
|  ✅ 优势：                        |
|  - 清晰地总结了图表的主要趋势     |
|  - 使用了适当的衔接词             |
|                                   |
+-----------------------------------+
|  💡 改进建议：                    |
|  - 增加更多的比较数据             |
|  - 丰富词汇多样性                 |
|  - 注意复数形式的使用             |
|                                   |
+-----------------------------------+
|  📝 示例修改：                    |
|  原句：The number is big.         |
|  修改：The number is significant. |
|                                   |
+-----------------------------------+
|  🔄 重新写作 | 保存报告          |
+-----------------------------------+
```

## 8. 设计规范

- 遵循8pt网格系统
- 使用统一的色彩方案和字体
- 确保所有交互元素有明确的视觉反馈
- 保持界面简洁，减少干扰元素
- 确保文本的可读性和易编辑性
- 提供清晰的导航和操作指引

## 9. 性能优化

- 实时语法检查采用增量检查，减少性能消耗
- 自动保存草稿功能采用节流机制，避免频繁请求
- 图表和图片采用懒加载技术
- 评分报告生成采用异步处理

## 10. 无障碍设计

- 支持键盘导航
- 提供屏幕阅读器兼容的标签
- 确保足够的颜色对比度
- 支持文本放大功能
- 提供清晰的错误提示信息

以上设计确保了写作模块具有良好的用户体验、高效的写作环境和有价值的AI反馈，帮助用户有效提升IELTS写作能力。
