# 发布前检查清单（阶段0基线）

## 1. 服务与配置

- [ ] 后端环境变量已配置（数据库路径、鉴权密钥、CORS）。
- [ ] 前端 `VITE_API_URL` 指向正确后端地址（默认 `http://127.0.0.1:8000`）。
- [ ] 数据库迁移已执行完成（含 `mistake_reviews` 表）。

## 2. 自动化冒烟

- [ ] 执行 `./scripts/smoke_core_flow.sh` 并全部通过。
- [ ] 关键后端测试通过：`tests/test_week2_backend_progress.py`（错题/词汇/听读/鉴权）。
- [ ] 前端构建通过：`npm --prefix frontend run build`。

## 3. 核心业务链路

- [ ] 登录失败、token失效、网络异常均显示中文错误提示。
- [ ] 词汇学习可完成“新增 -> 学习 -> 测试 -> 错题沉淀”闭环。
- [ ] 错题页可完成“筛选 -> 优先队列 -> 一键复习 -> 报告追踪”闭环。
- [ ] 报告页可显示错题趋势与复习成效图。

## 4. 数据一致性

- [ ] 词汇表无重复数据，唯一索引生效。
- [ ] 错题复习会写入复习日志（用于趋势和成效统计）。
- [ ] 关键筛选参数支持 URL 恢复（模块/题型/日期/队列排序与搜索）。

## 5. 视觉与体验

- [ ] 词汇模块输入框、下拉框样式统一。
- [ ] 词汇与错题页面风格与主体模块一致。
- [ ] 关键反馈文案中文化且语义明确。
