# 雅思学习智能体 - UI设计风格指南

## 1. 设计原则

### 1.1 核心设计理念

- **简洁直观**：减少视觉干扰，让用户快速找到所需功能
- **个性化体验**：根据用户水平和学习习惯定制界面内容
- **激励性设计**：通过视觉反馈和游戏化元素保持用户学习动力
- **专业可靠**：符合教育类应用的专业形象，建立用户信任
- **响应式适配**：Web优先设计，确保在桌面端提供最佳体验的同时兼容移动端

### 1.2 用户体验原则

- **清晰的学习路径**：从入门诊断到日常学习再到冲刺备考，提供明确的引导
- **及时的反馈机制**：练习后立即给出评估结果和改进建议
- **渐进式复杂度**：根据用户水平逐步解锁高级功能
- **情感化交互**：在用户受挫时给予鼓励，成功时给予肯定
- **最小化认知负担**：简化操作流程，减少用户思考成本

## 4. 布局系统

### 4.1 网格系统

- 采用8pt网格系统，确保所有元素对齐和间距一致
- **Web端网格**（Web优先）：
  - 顶部工具栏：100%宽度，拉通整个界面
  - 基础网格：12列布局，总宽度1200px，居中显示
  - 最大宽度：1440px（超宽屏自适应留白）
  - 内边距：32px（左右）
  - 侧边栏：固定宽度280px
  - 主内容区：弹性宽度，最小600px，内容居中排版
  - 右侧边栏：固定宽度320px（可选）
- **平板网格**：
  - 8列布局，总宽度100%
  - 内边距：24px（左右）
  - 侧边栏：折叠为抽屉式或转为顶部导航
- **移动端网格**：
  - 4列布局，总宽度100%
  - 内边距：16px（左右）
  - 单列布局，所有侧边栏转为顶部或底部导航

### 4.2 卡片设计

**基础卡片样式**（Web端）：

- **圆角**：12px（增强现代感）
- **阴影**：
  - 常规状态：0 4px 12px rgba(0, 0, 0, 0.06)
  - 悬停状态：0 8px 24px rgba(0, 0, 0, 0.12)
  - 选中/激活状态：0 6px 16px rgba(59, 130, 246, 0.15)
- **背景**：#FFFFFF
- **边框**：1px solid #E5E7EB（可选，用于区分内容区块）

**卡片变体**：

- **标准卡片**：完整阴影和边框，用于独立内容区块
- **无边框卡片**：仅背景色，用于内容分组
- **悬浮卡片**：更强阴影效果，用于需要突出的重要内容
- **统计卡片**：更大内边距，用于数据展示

**间距规范**：

- **卡片间距**：20px（水平和垂直）
- **内容间距**：
  - 标题到内容：16px
  - 内容到操作区：20px
  - 内部元素间距：8-16px

**响应式调整**：

- Web端：完整卡片效果，保持较大间距
- 平板：适当减小阴影和间距
- 移动端：简化为无边框卡片，减小圆角至8px

### 4.3 导航结构

**Web端导航**（Web优先）：

- **左侧边栏**：
  - 固定宽度：280px
  - 包含：Logo、用户信息、主导航菜单、学习统计概览
  - 滚动行为：内容可滚动，头部固定
  - 折叠功能：可收缩为图标模式（宽度80px）
- **顶部工具栏**：
  - 高度：64px
  - 包含：面包屑导航、全局搜索、通知中心、用户头像菜单、设置按钮
  - 固定定位：始终可见
- **内容区导航**：
  - 标签页导航：用于多内容区域切换
  - 侧边子导航：用于长页面内快速跳转

**移动端导航**：

- 底部导航栏：5个核心功能
- 顶部状态栏：标题、返回按钮、主要操作
- 侧边抽屉：扩展功能菜单

### 4.4 核心导航项

1. 首页/仪表盘
2. 学习中心（听说读写）
   - 听力训练
   - 阅读训练
   - 写作训练
   - 口语训练
3. 词汇学习
4. 错题本
5. 模拟考试
6. 学习报告
7. 个人中心

### 4.5 页面布局组件

**Web端页面结构**：
```
┌───────────────────────────────────────────────────────────────────────────────┐
│                                顶部工具栏                               │
├─────────┬──────────────────────────────────────────────────────────────────────┤
│         │                                                                      │
│ 左侧边栏 │                          主内容区域                               │
│ (280px) │                          （居中排版）                               │
│         │                                                                      │
└─────────┴──────────────────────────────────────────────────────────────────────┘
```

**内容区域布局**：

- **整体排版**：主内容区域采用居中排版，确保在各种屏幕尺寸下都有良好的视觉体验
- **顶部区域**：页面标题、操作按钮、统计概览
- **中部区域**：核心内容展示，采用卡片式布局，内容块居中对齐
- **底部区域**：分页、版权信息、辅助链接，与主内容区域保持一致的居中对齐方式

**Web端专用组件**：

- **面板**：可折叠的内容区块，用于组织复杂信息
- **分割面板**：可调整大小的双栏布局，用于对比查看内容
- **悬浮工具栏**：上下文相关的快捷操作
- **模态对话框**：用于复杂表单和重要操作确认

## 5. 交互设计

### 5.1 按钮设计

**Web端按钮样式**：

- **主要按钮**：
  - 样式：圆角10px，填充主色调#3B82F6，白色文字
  - 尺寸：高度48px，文字16px，最小宽度120px
  - 交互效果：
    - 悬停：背景色加深至#2563EB，阴影增强（0 4px 12px rgba(59, 130, 246, 0.3)）
    - 点击：轻微下沉效果（scale: 0.98），背景色变为#1D4ED8
    - 聚焦：添加2px蓝色外发光效果
- **次要按钮**：
  - 样式：圆角10px，描边主色调#3B82F6，主色调文字，透明背景
  - 尺寸：高度48px，文字16px，最小宽度120px
  - 交互效果：
    - 悬停：轻微填充主色调（背景色#EFF6FF），阴影增强
    - 点击：轻微下沉效果，描边颜色加深
- **辅助按钮**：
  - 样式：圆角10px，浅灰色背景#F3F4F6，灰色文字#6B7280
  - 尺寸：高度44px，文字15px
  - 交互效果：
    - 悬停：背景色变为#E5E7EB
    - 点击：轻微下沉效果

**按钮尺寸**：

- 大按钮：高度56px，文字18px（Web端专用）
- 标准按钮：高度48px，文字16px
- 中按钮：高度40px，文字15px
- 小按钮：高度32px，文字14px
- 微型按钮：高度24px，文字12px（图标按钮）

### 5.2 表单设计

**Web端表单控件**：

- **输入框**：
  - 样式：圆角10px，浅灰色背景#F3F4F6，1px灰色边框#D1D5DB
  - 尺寸：高度44px，文字16px，内边距16px
  - 交互效果：
    - 悬停：边框颜色变为#9CA3AF，背景色轻微变浅
    - 聚焦：边框颜色变为#3B82F6，背景色变为白色，添加2px蓝色外发光效果
    - 错误：边框颜色变为#EF4444，显示红色错误提示文字
- **下拉菜单**：
  - 样式：与输入框一致，右侧添加向下箭头图标
  - 交互效果：
    - 悬停：边框颜色变化
    - 展开：平滑淡入动画，菜单项悬停高亮
- **复选框/单选框**：
  - 样式：圆角4px，20px大小，选中时填充主色调
  - 交互效果：
    - 点击：平滑的选中/取消选中动画
    - 悬停：边框颜色变化

**表单布局**（Web优先）：

- 标签位于输入框上方，使用14px文字
- 输入框与标签间距8px
- 表单字段间距24px
- 提交按钮与表单内容间距32px
- 验证反馈：实时显示，位于输入框下方8px处

### 5.3 微动效

**Web端专用微交互**：

- **卡片交互**：
  - 悬停：轻微上浮（translateY: -4px），阴影增强（0 8px 24px rgba(0, 0, 0, 0.12)）
  - 点击：轻微下沉效果（scale: 0.99）
  - 加载：骨架屏动画（渐变流动效果）
- **导航菜单**：
  - 菜单项悬停：背景色变为#EFF6FF，文字颜色加深，左侧添加蓝色指示条
  - 子菜单展开：平滑淡入动画，菜单项依次出现
  - 侧边栏折叠/展开：平滑过渡动画（0.3秒）
- **数据可视化**：
  - 图表加载：数据点依次出现动画
  - 数值变化：平滑的数字增长动画
- **按钮交互**：
  - 主要按钮：悬停时背景色变化+阴影增强
  - 次要按钮：悬停时轻微填充效果
- **页面过渡**：
  - 路由切换：平滑的淡入淡出效果（0.4秒）
  - 模态框：从中心缩放进入，背景模糊效果
  - 抽屉式菜单：从侧边滑入，背景变暗

**通用微动效**：

- 数据加载：骨架屏或脉冲动画
- 成就达成：徽章弹出动画+进度条填充动画
- 下拉菜单：平滑展开/收起动画（0.2秒）
- 滚动效果：滚动时导航栏背景透明度变化，回到顶部按钮渐入

### 5.4 状态设计

- **成功状态**：绿色图标 + 成功提示文字
- **错误状态**：红色图标 + 错误提示文字
- **警告状态**：黄色图标 + 警告提示文字
- **信息状态**：蓝色图标 + 信息提示文字
- **加载状态**：旋转动画或进度条
- **空状态**：友好的提示文字 + 引导用户操作的按钮

## 6. 视觉元素

### 6.1 图标系统

**Web端图标规范**：

- **图标风格**：
  - 主要图标：线性图标，线条粗细2px，圆角设计
  - 强调图标：填充图标，使用主色调或辅助色
  - 状态图标：微型图标（16px），用于状态指示
- **图标尺寸**：
  - 导航图标：24px（Web端侧边栏）
  - 功能图标：20px（按钮、卡片内）
  - 状态图标：16px（状态指示、标签）
  - 微型图标：12px（文本内、小按钮）
  - 超大图标：32px（数据卡片、重要功能入口）
- **图标使用**：
  - 导航菜单：左侧图标+文字，图标与文字间距12px
  - 按钮：图标与文字间距8px，图标位置根据功能调整
  - 卡片：左上角或右上角图标，用于功能分类
  - 数据可视化：与图表配套的说明图标
- **图标颜色**：
  - 主要功能：主色调#3B82F6
  - 辅助功能：中灰色#6B7280
  - 成功状态：绿色#10B981
  - 警告状态：橙色#F59E0B
  - 错误状态：红色#EF4444
  - 智能功能：紫色#8B5CF6

### 6.2 数据可视化

**Web端数据可视化组件**：

- **能力雷达图**：
  - 尺寸：400x400px（Web端专用）
  - 特点：彩色填充区域，悬停显示详细数据，支持多维度对比
  - 交互：点击维度标签可突出显示对应能力
- **学习进度组件**：
  - **环形进度条**：直径120px，显示总体学习进度，中心显示百分比
  - **线性进度条**：高度8px，圆角设计，显示单项任务进度
  - **阶梯式进度**：展示学习路径中的里程碑完成情况
- **趋势分析图表**：
  - **折线图**：展示分数变化、学习时长趋势，支持多数据系列对比
  - **柱状图**：对比不同科目成绩、学习时长分布
  - **面积图**：展示学习量累积趋势
- **分布图表**：
  - **饼图/环形图**：展示时间分配、题型占比
  - **热力图**：展示学习频率、薄弱点分布（Web端大屏幕专用）
  - **散点图**：分析练习量与分数的相关性

**数据可视化规范**：

- 图表标题：使用18px文字，位于图表上方
- 图例：清晰展示数据系列，支持悬停高亮
- 数据标签：悬停时显示详细数据，重要数据可直接标注

## 7. 响应式设计

### 7.1 断点设计（Web优先）

```
超宽屏：≥1440px - 完整三栏布局，最大宽度1440px
宽屏：1200px - 1439px - 三栏布局，固定宽度1200px
中屏：1024px - 1199px - 三栏布局，侧边栏可折叠
平板：768px - 1023px - 双栏布局，侧边栏转为抽屉
小屏平板：640px - 767px - 单栏布局，顶部导航
移动端：< 640px - 单栏布局，底部导航
```

### 7.2 Web优先适配原则

- **Web端优先**：首先设计完整的Web端体验，然后逐步适配到小屏幕设备
- **内容优先级**：在小屏幕上优先展示核心学习功能，次要功能可折叠或放入菜单
- **布局转换**：
  - 1024px以下：右侧边栏转为抽屉式或隐藏
  - 768px以下：左侧边栏转为顶部导航或抽屉菜单
  - 640px以下：所有导航转为底部导航栏
- **组件适配**：
  - 卡片：从多列布局转为单列布局，减少阴影和圆角
  - 图表：从复杂图表转为简化图表或列表展示
  - 表单：从多列布局转为单列布局
  - 按钮：从大尺寸转为标准尺寸，减少最小宽度
- **字体缩放**：
  - Web端：完整字体层级（H0-H4-正文-辅助文字-小号文字-微文字）
  - 平板：移除H0层级，缩小其他层级字体大小
  - 移动端：仅保留H1-H3-正文-辅助文字-小号文字，进一步缩小字体大小
- **交互适配**：
  - Web端：丰富的鼠标悬停和点击效果
  - 移动端：优化触摸目标大小（≥48px），减少复杂动画
- **图片和媒体**：
  - 响应式图片：根据屏幕尺寸加载不同分辨率
  - 视频：自适应容器宽度，Web端支持全屏播放

### 7.3 组件响应式指南

**侧边栏**：

- ≥1024px：固定宽度280px，完整显示
- 768px-1023px：可折叠为80px宽度（仅显示图标）
- <768px：转为顶部汉堡菜单，点击展开抽屉式菜单

**顶部工具栏**：

- ≥1024px：完整显示所有功能（面包屑、搜索、通知、用户菜单）
- 768px-1023px：隐藏面包屑，搜索栏缩小
- <768px：仅显示标题、返回按钮和主要操作

**卡片布局**：

- ≥1200px：4列布局
- 1024px-1199px：3列布局
- 768px-1023px：2列布局
- <768px：1列布局

**数据可视化**：

- ≥1024px：完整图表（雷达图、热力图、趋势图）
- 768px-1023px：简化图表（折线图、柱状图）
- <768px：列表或进度条展示，点击可展开详细图表

**表格**：

- ≥1024px：完整表格展示
- 768px-1023px：水平滚动表格
- <768px：转为卡片式列表
