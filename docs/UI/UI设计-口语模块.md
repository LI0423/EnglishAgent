# UI设计-口语模块

## 1. 设计目标

口语模块的UI设计旨在提供一个模拟真实考试环境的口语练习平台，同时确保用户能够方便地进行录音、获得AI评估和学习反馈。设计遵循以下原则：

- **模拟真实考试环境**：提供与IELTS考试相似的题目类型和时间限制
- **直观的录音控制**：清晰的录音按钮和时间显示
- **实时视觉反馈**：录音状态、音量波动可视化
- **详细的评分报告**：多维度的口语能力评估
- **个性化改进建议**：针对发音、流利度、词汇等方面的具体建议
- **响应式适配**：在不同设备上提供一致的练习体验

## 2. 页面结构

### 2.1 核心功能模块

| 功能模块 | 描述 |
| --------- | ------ |
| 题目展示区 | 显示口语题目、类型（Part 1/2/3）、准备时间和答题时间 |
| 录音控制区 | 提供录音、暂停、停止等控制按钮 |

| 反馈建议 | 提供具体的改进方向和示例 |

- 波形样式：柱状波形，平滑过渡

- 数字显示：大号字体，居中对齐

## 4. 交互设计

### 4.1 核心交互流程

#### 4.1.1 口语练习流程

```
1. 用户选择口语部分（Part 1/2/3）
2. 系统展示题目和准备时间
3. 准备时间倒计时
4. 提示开始录音
5. 用户点击录音按钮开始答题
6. 实时显示音量波形和答题时间
7. 答题时间结束或用户手动停止录音
8. 系统处理录音并生成评估报告
```

#### 4.1.2 录音交互

- 点击录音按钮开始录音，按钮变为红色并脉冲动画
- 实时显示音量波形
- 点击暂停按钮暂停录音，按钮变为黄色
- 点击停止按钮结束录音，按钮变回蓝色
- 提供重新录制功能

### 4.2 不同口语部分的特殊设计

#### 4.2.1 Part 1（日常话题）

- 显示多个相关问题
- 每个问题答题时间：30-60秒
- 自动切换到下一个问题
- 支持跳过和重新回答

#### 4.2.2 Part 2（个人陈述）

- 提供1分钟准备时间
- 显示提示要点（who/what/where/when/why）
- 2分钟答题时间
- 支持笔记功能（可选）

#### 4.2.3 Part 3（深入讨论）

- 显示一系列相关问题
- 每个问题答题时间：60-90秒
- 问题难度逐渐增加
- 支持深入思考时间

## 5. 响应式设计

### 5.1 移动端适配（320-767px）

- 垂直堆叠所有内容

- 音量波形自适应宽度

### 5.2 平板适配（768-1023px）

- 增加元素间距，提高可读性
- 显示完整的控制按钮文本
- 增大音量波形显示区域

### 5.3 网页端适配（1024px+）

- 采用左右分栏布局
- 提供更大的题目展示区域
- 显示过往练习历史
- 支持键盘快捷键操作

## 7. 评估报告页面

### 7.1 页面结构

| 区域 | 内容 |
| ------ | ------ |
| 总分区域 | 显示总体得分（1-9分） |
| 分项评分 | 展示四个评分维度（流利度、词汇、语法、发音） |
| 发音分析 | 具体发音问题和改进建议 |
| 流利度分析 | 停顿次数、语速变化等数据 |
| 词汇语法 | 词汇丰富度和语法准确性评估 |
| 示例对比 | 展示标准发音和用户发音的对比 |
| 重练功能 | 允许用户重新练习同一题目 |


## 8. 设计规范

- 遵循8pt网格系统
- 使用统一的色彩方案和字体
- 确保所有交互元素有明确的视觉反馈
- 保持界面简洁，减少干扰元素
- 确保音频控件的易用性
- 提供清晰的时间提示和进度反馈

## 9. 性能优化

- 录音采用高效的音频编码格式
- 实时波形显示采用优化的渲染算法
- 评估报告生成采用异步处理
- 历史录音采用分页加载

## 10. 无障碍设计

- 支持键盘导航
- 提供屏幕阅读器兼容的标签
- 确保足够的颜色对比度
- 支持文本放大功能
- 提供清晰的音频反馈

以上设计确保了口语模块具有良好的用户体验、真实的考试模拟环境和有价值的AI反馈，帮助用户有效提升IELTS口语能力。
