# 首页/仪表盘 UI设计

## 1. 设计目标

- **核心目标**：打造一个现代化、直观且高效的学习仪表盘，为用户提供清晰的学习进度概览和核心功能快捷入口
- **用户体验**：极简设计减少认知负担，突出关键信息，提供流畅的学习路径引导，增强用户学习动力
- **功能完整性**：整合核心学习模块，支持个性化学习计划、进度追踪和智能推荐
- **视觉一致性**：遵循现代设计美学，保持品牌视觉统一，创造专业且愉悦的学习环境
- **性能优化**：轻量化设计确保快速加载，响应式布局适配不同屏幕尺寸
- **Web优先设计**：专为桌面端优化布局，最大化屏幕空间利用率，提供沉浸式学习体验

## 2. 页面结构

### 2.1 核心组件（Web端优化）

- **左侧导航栏**：固定导航，包含Logo、核心功能菜单和用户信息，提供沉浸式导航体验，固定宽度280px
- **顶部工具栏**：100%宽度拉通整个界面，无左右边距，显示通知、设置快捷入口和当前时间
- **欢迎与概览区**：个性化问候与关键学习数据概览卡片，突出重要成就，严格居中排版
- **核心功能矩阵**：听说读写四大模块的直观入口，显示实时学习状态和快速开始按钮，居中布局
- **学习洞察区**：整合进度图表与词汇统计，提供全面学习视角和数据分析，居中展示
- **智能推荐区**：基于学习数据的个性化内容推荐，聚焦薄弱环节提升，内容居中
- **今日任务清单**：聚焦当日核心学习任务，支持快速标记完成和进度跟踪，内容居中

## 3. 视觉设计

### 3.1 色彩应用

- **主色调**：`#3B82F6`（蓝色）- 用于主要按钮、关键指标和高亮元素，代表专业、信任和稳定
  - 变体：`#2563EB`（深）、`#60A5FA`（中）、`#DBEAFE`（浅）、`#DBEAFE`（极浅）
- **辅助色**：`#F59E0B`（橙色）- 用于警告、提醒和次要强调，代表活力和能量
  - 变体：`#D97706`（深）、`#FBBF24`（中）、`#FEF3C7`（浅）、`#FEF3C7`（极浅）
- **成功色**：`#10B981`（绿色）- 用于成功状态、完成标记，代表成长和进步
  - 变体：`#059669`（深）、`#34D399`（中）、`#D1FAE5`（浅）、`#D1FAE5`（极浅）
- **危险色**：`#EF4444`（红色）- 用于错误提示、未完成状态，代表警告和需要关注
  - 变体：`#DC2626`（深）、`#F87171`（中）、`#FEE2E2`（浅）、`#FEE2E2`（极浅）
- **中性色**：
  - 背景：`#F3F4F6`（主背景）、`#FFFFFF`（卡片背景）
  - 文本：`#1F2937`（主要文本）、`#4B5563`（次要文本）、`#6B7280`（辅助文本）、`#9CA3AF`（提示文本）
  - 边框：`#E5E7EB`（常规边框）、`#D1D5DB`（强调边框）
  - 阴影：`rgba(0, 0, 0, 0.06)`（常规阴影）、`rgba(0, 0, 0, 0.12)`（强调阴影）

- **图标风格**：线性图标（Linear Icons），保持简洁现代的视觉语言
- **主要图标尺寸**：
  - 导航图标：24px（网页端）/ 24px（移动端）
  - 功能图标：24px（网页端）/ 28px（移动端）
  - 图表图标：16px（网页端/移动端）
  - 状态图标：12px（网页端/移动端）
- **图标颜色**：
  - 主要图标：`#3B82F6`（主色调）
  - 次要图标：`#6B7280`（中性色）
  - 成功状态：`#10B981`（成功色）
  - 警告状态：`#F59E0B`（辅助色）

## 4. 交互设计

### 4.1 用户流程

1. **用户登录**：成功登录后进入首页/仪表盘，显示个性化欢迎界面
2. **概览浏览**：快速扫描学习概览卡片，了解总进度、词汇量等关键指标
3. **功能选择**：点击核心功能卡片，进入相应的学习模块（听力、阅读、写作、口语）
4. **深度分析**：查看学习趋势图表，分析学习模式和薄弱环节
5. **个性化学习**：浏览智能推荐内容，选择针对性练习
6. **任务管理**：查看并完成今日任务，标记进度
7. **成就查看**：查看学习成就与里程碑，获取学习动力

### 4.2 微交互设计

- **全局交互效果**：
  - 页面加载：内容区域渐进式淡入，关键元素依次出现
  - 导航切换：页面内容平滑过渡（淡入淡出 + 轻微位移）
  - 滚动效果：导航栏样式随滚动变化，关键元素固定定位

- **按钮交互**：
  - 悬停状态：背景色加深 5%，阴影增强，轻微上浮（2px）
  - 点击状态：轻微按压效果（缩放 0.98），伴随微妙的波纹动画
  - 禁用状态：透明度降低至 60%，鼠标指针变为禁止状态
  - 加载状态：显示旋转加载动画，禁用点击事件

- **卡片交互**：
  - 悬停状态：轻微上浮（4px），阴影增强为0px 12px 24px rgba(0, 0, 0, 0.12)
  - 点击状态：轻微缩放（0.99），边框颜色变为 `#4A6CF7`
  - 焦点状态：显示蓝色边框高亮，支持键盘导航

- **进度与成就交互**：
  - 任务完成：进度条平滑动画增长（0.5秒），伴随完成音效
  - 成就达成：弹出庆祝动画（徽章旋转 + 烟花效果），显示成就详情
  - 数据更新：数字变化时使用平滑的计数动画

- **通知与提示交互**：
  - 新通知：图标数字角标跳动动画，背景色闪烁
  - 通知面板：平滑滑入/滑出，支持左右滑动切换通知类型
  - 操作反馈：成功/错误提示以顶部 toast 形式出现，3秒后自动消失

### 4.3 数据可视化交互

- **环形进度图交互**：
  - 加载动画：圆环从0%到当前进度的平滑过渡（1秒）
  - 悬停效果：圆环宽度增加2px，中心文字放大1.1倍
  - 点击交互：点击显示详细进度报告

- **趋势图交互**：
  - 数据点悬停：显示详细数据 tooltip，包含日期、数值和对比信息
  - 时间范围切换：支持日/周/月/年视图切换，图表平滑重绘
  - 缩放功能：支持鼠标滚轮缩放特定时间区间，拖拽平移查看

- **词汇量统计交互**：
  - 数值变化：词汇量增长时显示 +N 的动画提示
  - 点击查看：点击进入词汇学习详情页面
  - 历史记录：悬停显示最近7天词汇量变化趋势

### 4.4 导航与菜单交互

- **左侧导航栏交互**：
  - 菜单项悬停：背景色渐变变化，文字和图标颜色平滑过渡
  - 激活状态：左侧边框颜色动画滑入，背景色同步变化
  - 折叠功能：支持点击收起/展开导航栏，内容区域自适应宽度

- **顶部状态栏交互**：
  - 通知图标：点击展开下拉菜单，显示未读通知列表
  - 设置图标：点击展开设置面板，支持快速调整设置
  - 时间显示：鼠标悬停显示完整日期和时区信息

## 5. 响应式设计

### 5.1 Web优先设计原则

- **核心策略**：以桌面端体验为核心，确保大屏幕下的最佳布局和功能展示
- **渐进增强**：在保证桌面端体验的基础上，为平板和移动设备提供适配方案
- **内容优先级**：在小屏幕上优先展示核心功能和关键信息

### 5.2 桌面端（1200px +）

- **布局**：左侧固定导航（240px） + 右侧内容区（自适应宽度）
- **内容结构**：
  - 欢迎区：100% 宽度
  - 概览卡片：2x2 网格排列
  - 核心功能：4x1 或 2x2 网格排列
  - 学习洞察：左侧图表（60%）+ 右侧推荐（40%）
  - 任务与成就：左侧任务（60%）+ 右侧成就（40%）
- **图表展示**：完整数据展示，支持多维度分析和交互
- **交互体验**：丰富的微交互和动画效果

### 5.3 平板端（768px - 1199px）

- **布局**：
  - 1024px - 1199px：左侧导航（200px） + 右侧内容区
  - 768px - 1023px：顶部导航 + 内容区（单列流式布局）
- **内容调整**：
  - 概览卡片：2x2 网格排列
  - 核心功能：2x2 网格排列
  - 学习洞察：上下排列（图表在上，推荐在下）
  - 任务与成就：上下排列（任务在上，成就在下）
- **字体与间距**：适当缩小字体大小和间距，保持内容可读性

### 5.4 移动端（320px - 767px）

- **布局**：单列流式布局，顶部导航 + 底部导航
- **内容优先级**：
  - 必须保留：欢迎区、核心功能、今日任务、学习概览
  - 可折叠：学习趋势、智能推荐、成就系统
- **交互优化**：
  - 简化导航菜单，使用汉堡菜单
  - 卡片式布局，增加触摸区域
  - 简化图表，突出关键数据

### 5.5 响应式断点策略

- **超大屏幕**：≥ 1440px - 特殊优化，增加内容区最大宽度
- **大屏幕**：1200px - 1439px - 默认桌面端布局
- **中屏幕**：1024px - 1199px - 压缩左侧导航宽度
- **小屏幕**：768px - 1023px - 切换为顶部导航
- **移动屏幕**：< 768px - 切换为移动端布局

### 5.6 响应式组件适配

- **导航栏**：
  - 桌面端：左侧固定导航
  - 平板端：可折叠左侧导航或顶部导航
  - 移动端：汉堡菜单 + 底部导航
- **卡片组件**：
  - 桌面端：固定宽度卡片，多列排列
  - 平板端：自适应宽度卡片，2列排列
  - 移动端：100%宽度卡片，单列排列
- **图表组件**：
  - 桌面端：完整图表，支持丰富交互
  - 平板端：简化图表，保留核心功能
  - 移动端：极简图表，仅显示关键数据
- **按钮组件**：
  - 桌面端：文字按钮、图标按钮、填充按钮
  - 平板端：适当增大按钮尺寸
  - 移动端：大尺寸触摸按钮，减少文字按钮

## 9. 设计迭代说明
