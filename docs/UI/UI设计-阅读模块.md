# 阅读模块 UI设计

## 1. 设计目标

- **核心目标**：提供舒适的长篇文本阅读体验，支持多种IELTS阅读题型作答
- **用户体验**：优化文本可读性，提供高效的题目导航和作答方式
- **功能完整性**：支持文本标注、词汇查询、笔记功能、答题记录等
- **学习效果**：通过分段阅读、重点标记提升阅读理解能力
- **视觉一致性**：遵循品牌设计语言，保持与其他页面的视觉统一

## 2. 页面结构

### 2.1 核心组件

- **顶部导航栏**：返回、题目信息、设置、时间显示
- **文章浏览区**：文本内容、段落标记、图片展示
- **标注工具栏**：高亮、下划线、笔记工具
- **词汇助手**：单词查询、释义展示
- **题目导航**：题目列表、当前题目标记
- **题目展示区**：题目文本、选项（根据题型变化）
- **作答区域**：答案输入/选择控件
- **操作按钮区**：上一题、下一题、提交答案、查看解析
- **辅助功能**：全文检索、字体大小调节、背景色切换
- **进度追踪**：题目完成状态、时间进度条
- **底部导航**：移动端核心功能快速切换

## 3. 视觉设计

### 3.1 色彩应用

- **主色调**：`#4A6CF7`（蓝色）- 用于主要按钮、高亮标记、当前题目指示
- **辅助色**：`#F7B955`（橙色）- 用于警告、时间提示、次要强调
- **成功色**：`#50CD89`（绿色）- 用于正确答案、完成状态
- **危险色**：`#F1416C`（红色）- 用于错误答案、警告提示
- **中性色**：`#F8F9FA`（背景）、`#86909C`（次要文本）、`#212529`（主要文本）
- **文本背景**：`#FFFFFF`（默认）/ `#F5F5F5`（护眼模式）
- **标注颜色**：
  - 黄色高亮：`#FFF3CD`
  - 蓝色高亮：`#D1ECF1`
  - 粉色高亮：`#F8D7DA`
  - 绿色高亮：`#D4EDDA`
- **边框颜色**：`#E9ECEF`（分隔线、边框）

### 3.2 排版设计

- **文章标题**：Inter 600, 24px, `#212529`
- **文章段落**：Inter 400, 18px, `#495057`（移动端）/ 20px（网页端）
- **段落标记**：Inter 500, 14px, `#86909C`
- **题目类型**：Inter 600, 16px, `#4A6CF7`
- **题目文本**：Inter 500, 18px, `#212529`
- **选项文本**：Inter 400, 16px, `#495057`（移动端）/ 18px（网页端）
- **辅助文字**：Inter 400, 14px, `#86909C`
- **按钮文本**：Inter 500, 16px, `#FFFFFF`（主要按钮）/ `#4A6CF7`（次要按钮）

### 3.3 组件设计

#### 3.3.1 顶部导航栏

- **高度**：60px
- **背景色**：`#FFFFFF`
- **包含元素**：返回图标（24px）、题目信息（题型、文章标题）、时间显示、设置图标（24px）
- **阴影**：1px 2px 8px rgba(0, 0, 0, 0.08)

#### 3.3.2 文章浏览区

- **背景色**：`#FFFFFF`（可切换）
- **内边距**：20px
- **段落间距**：1.8倍行高，段落间额外20px间距
- **段落标记**：左侧垂直红线（4px宽），颜色 `#4A6CF7`
- **图片展示**：居中显示，最大宽度100%，边框圆角8px
- **文本选择**：支持自由选择文本进行标注或词汇查询

#### 3.3.3 标注工具栏

- **高度**：56px
- **背景色**：`#FFFFFF`
- **按钮样式**：圆形（40px），背景色 `#F8F9FA`，图标颜色 `#495057`
- **包含工具**：高亮（多色选择）、下划线、删除线、添加笔记
- **展开/收起**：移动端可折叠，点击展开完整工具栏
- **边框**：顶部和底部1px solid `#E9ECEF`

#### 3.3.4 词汇助手

- **触发方式**：长按单词或点击已选单词
- **样式**：弹出卡片，圆角12px，背景色 `#FFFFFF`，阴影 0px 4px 16px rgba(0, 0, 0, 0.1)
- **内容**：单词、音标、释义、例句、词性
- **大小**：最大宽度300px，自动换行

#### 3.3.5 题目导航

- **背景色**：`#FFFFFF`
- **布局**：水平滚动（移动端）/ 垂直列表（网页端）
- **题目项**：圆形数字按钮（32px），背景色 `#F8F9FA`，文字颜色 `#495057`
- **当前题目**：背景色 `#4A6CF7`，文字颜色 `#FFFFFF`
- **已完成题目**：背景色 `#50CD89`，文字颜色 `#FFFFFF`
- **未完成题目**：背景色 `#F8F9FA`，文字颜色 `#495057`

#### 3.3.6 题目展示区

- **背景色**：`#FFFFFF`
- **内边距**：20px
- **题目类型标签**：圆角矩形（8px），背景色 `#E3E7FF`，文字颜色 `#4A6CF7`，内边距 8px 16px
- **题目文本**：行高1.6，确保长文本可读性
- **关联段落**：显示题目关联的文章段落编号，便于定位

#### 3.3.7 作答区域

根据题型不同，作答区域会有相应变化：

- **选择题**：
  - 选项容器：白色背景，圆角8px，边框1px solid `#E9ECEF`，内边距16px
  - 选中状态：边框颜色 `#4A6CF7`，背景色 `#E3E7FF`
  - 正确答案：边框颜色 `#50CD89`，背景色 `#E8FFF3`
  - 错误答案：边框颜色 `#F1416C`，背景色 `#FFF0F3`

- **匹配题**：
  - 两列布局：左侧题干列表，右侧选项列表
  - 连线样式：蓝色线条连接匹配项
  - 交互方式：点击选择匹配

- **填空题**：
  - 输入框：高度48px，白色背景，圆角8px，边框1px solid `#E9ECEF`
  - 聚焦状态：边框颜色 `#4A6CF7`，添加轻微阴影

- **True/False/Not Given**：
  - 三选项水平排列，每个选项占1/3宽度
  - 选项样式：圆角8px，背景色 `#F8F9FA`，选中后变色

#### 3.3.8 操作按钮区

- **布局**：水平排列，两端对齐
- **主要按钮**：背景色 `#4A6CF7`，文字颜色 `#FFFFFF`，圆角8px，高度48px，内边距20px
- **次要按钮**：背景色 `#F8F9FA`，文字颜色 `#495057`，圆角8px，高度48px，内边距20px
- **按钮间距**：12px

#### 3.3.9 辅助功能区

- **高度**：56px
- **背景色**：`#FFFFFF`
- **按钮样式**：图标+文字，圆角8px，背景色 `#F8F9FA`，内边距12px
- **包含功能**：字体放大/缩小、背景色切换、全文检索、刷新
- **边框**：顶部1px solid `#E9ECEF`

#### 3.3.10 底部导航栏（移动端）

与首页/仪表盘保持一致：

- **高度**：60px
- **背景色**：`#FFFFFF`
- **阴影**：-1px -2px 8px rgba(0, 0, 0, 0.06)
- **图标尺寸**：24px
- **激活状态**：图标和文字颜色 `#4A6CF7`

## 3. 交互设计

### 3.1 用户流程

1. **进入模块**：从首页点击阅读模块进入
2. **选择练习**：选择题型、难度、套题等
3. **开始练习**：进入文章页面，浏览文本内容
4. **标注重点**：使用标注工具标记文章重点
5. **查询词汇**：长按单词查看释义
6. **作答题目**：按顺序或跳转到特定题目作答
7. **导航**：通过题目列表或上一题/下一题切换
8. **提交答案**：完成所有题目后提交
9. **查看结果**：查看得分和详细解析
10. **错题记录**：系统自动记录错题，用于复习

### 3.2 微交互设计

- **文本标注**：
  - 高亮：选择文本后弹出标注选项，点击后颜色填充
  - 笔记：添加笔记时弹出输入框，保存后显示笔记图标
  - 删除标注：长按标注内容显示删除选项

- **词汇查询**：
  - 长按单词：弹出词汇卡片，显示释义
  - 卡片交互：可滑动查看更多释义或例句

- **题目导航**：
  - 点击题目项：平滑跳转到对应题目，更新当前标记
  - 上一题/下一题：页面平滑过渡，保持阅读位置

- **作答反馈**：
  - 选项选择：点击时有轻微缩放效果，选中状态即时反馈
  - 答案提交：进度条动画，得分统计渐入
  - 解析展示：点击展开/收起详细解析

- **辅助功能**：
  - 字体大小调节：实时预览效果，有最小/最大限制
  - 背景色切换：即时生效，记忆用户偏好
  - 全文检索：输入关键词后高亮显示所有匹配项

### 3.3 特殊场景处理

- **长文本浏览**：支持章节导航、段落折叠，避免滚动疲劳
- **时间管理**：时间进度条颜色随剩余时间变化（绿色→黄色→红色）
- **网络中断**：自动保存当前进度和标注内容
- **退出练习**：提示是否保存进度，确认后退出
- **屏幕旋转**：自适应横屏/竖屏布局，优化阅读体验

## 4. 题型适配设计

### 4.1 选择题

- **布局**：垂直排列选项，每个选项占一行
- **选择控件**：圆形单选按钮或方形复选框
- **作答反馈**：选中状态即时显示

### 4.2 匹配题

- **两列布局**：左侧为待匹配项，右侧为目标项
- **交互方式**：点击选择匹配，支持取消重新选择
- **可视化**：匹配成功后显示连接线

### 4.3 True/False/Not Given

- **三选项水平排列**：节省空间，便于快速选择
- **选项样式**：清晰的文字说明，避免歧义
- **作答反馈**：即时显示选中状态

### 4.4 填空题

- **输入框**：根据上下文调整宽度，支持长文本输入
- **字数限制**：实时显示已输入字数
- **自动补全**：提供可能的答案建议

### 4.5 段落信息匹配

- **段落标记**：文章中清晰标记段落序号
- **选项列表**：垂直排列待匹配的信息点
- **交互方式**：点击选择对应段落

## 5. 响应式设计

### 5.1 移动端（320px - 767px）

- **布局**：单列流式布局，文章和题目垂直排列
- **文章浏览**：支持双指缩放，优化触控体验
- **标注工具**：折叠式设计，点击展开
- **题目导航**：水平滚动列表，节省垂直空间
- **辅助功能**：底部弹出式菜单

### 5.2 平板端（768px - 1023px）

- **布局**：双列布局（文章和题目并排显示）
- **标注工具**：完整显示在文章下方
- **题目导航**：垂直列表，固定在题目区域上方
- **词汇助手**：弹出卡片大小适配平板屏幕

### 5.3 网页端（1024px +）

- **布局**：左侧导航 + 右侧内容区，文章和题目左右分栏
- **文章浏览**：更大的阅读区域，支持更多标注颜色
- **题目导航**：垂直固定列表，支持题目筛选
- **辅助功能**：完整工具栏，提供更多自定义选项
- **响应式调整**：在小屏设备上自动切换为堆叠布局

## 9. 设计迭代说明

本设计基于用户需求和阅读学习场景进行了多次迭代，重点关注：

1. **文本可读性**：优化字体大小、行高和段落间距，提升长篇文本阅读体验
2. **标注功能**：提供多种标注工具，帮助用户标记重点内容
3. **词汇支持**：即时词汇查询，降低阅读障碍
4. **题型适配**：灵活支持多种IELTS阅读题型
5. **时间管理**：清晰的时间显示和进度提示

后续将根据用户反馈和使用数据进行进一步优化和迭代。
