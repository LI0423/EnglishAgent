# 雅思学习智能体 - 登录/注册页面设计

## 1. 设计目标

- 提供简洁直观的登录/注册流程，减少用户流失
- 建立品牌第一印象，传达专业可靠的教育形象
- 支持多种登录方式，满足不同用户习惯
- 确保表单验证和错误提示清晰明确
- 提供流畅的登录/注册切换体验
- 适配移动端和Web端不同设备

## 2. 页面结构

### 2.1 核心组件

#### 2.1.1 品牌区域

- **Logo**：应用标识，位于页面顶部中央

## 3. 视觉设计

### 3.1 色彩应用

- **背景色**：#F3F4F6（极浅灰），营造简洁清爽的氛围
- **卡片背景**：#FFFFFF（白色），表单区域使用白色卡片，增强层次感
- **主色调**：#3B82F6（蓝色），应用于Logo、主要按钮和强调元素
- **辅助色**：
  - 绿色#10B981：成功状态
  - 红色#EF4444：错误状态
  - 灰色#9CA3AF：次要文本和边框

### 3.2 排版设计

- **标题**：24px / 32px，700 weight，深灰色#1F2937
- **正文**：16px / 24px，400 weight，深灰色#1F2937
- **辅助文字**：14px / 20px，400 weight，中灰色#4B5563
- **链接文字**：14px / 20px，400 weight，主色调#3B82F6

### 3.3 表单元素设计

- **输入框**：
  - 高度：48px
  - 圆角：8px
  - 背景色：#F9FAFB（浅灰）
  - 边框：1px solid #E5E7EB（浅灰）
  - 聚焦状态：边框颜色变为#3B82F6（主色调），添加轻微阴影
  - 错误状态：边框颜色变为#EF4444（红色），显示错误图标

- **按钮设计**：
  - **主要按钮（登录/注册）**：
    - 高度：48px
    - 圆角：8px
    - 背景色：#3B82F6（主色调）
    - 文字颜色：#FFFFFF（白色）
    - 悬停状态：背景色加深10%，轻微阴影
    - 点击状态：scale: 0.98

  - **第三方登录按钮**：
    - 高度：44px
    - 圆角：8px
    - 背景色：#FFFFFF（白色）
    - 边框：1px solid #E5E7EB（浅灰）
    - 图标+文字组合
    - 悬停状态：背景色变为#F3F4F6（极浅灰）

### 3.4 图标设计

- **输入框图标**：
  - 邮箱：信封图标
  - 手机号：手机图标
  - 密码：锁图标
  - 显示/隐藏密码：眼睛图标

- **第三方登录图标**：
  - 微信：微信图标
  - QQ：QQ图标
  - Apple ID：Apple图标
  - Google：Google图标

- **按钮图标**：
  - 微信：微信Logo
  - QQ：QQ Logo
  - Apple ID：Apple Logo
  - Google：Google Logo

- **状态图标**：
  - 成功：对勾图标（绿色）
  - 错误：叉号图标（红色）
  - 警告：感叹号图标（黄色）

## 4. 交互设计

### 4.1 登录流程

1. **用户进入登录页面**：显示品牌Logo、口号和登录表单
2. **输入账号密码**：
   - 实时验证邮箱/手机号格式
   - 密码强度提示（注册时）
3. **点击登录按钮**：
   - 表单验证通过：提交登录请求
   - 表单验证失败：显示错误提示
4. **登录成功**：跳转到首页/仪表盘
5. **登录失败**：显示错误提示（如账号密码错误）

### 4.2 注册流程

1. **用户进入注册页面**：显示品牌Logo、口号和注册表单
2. **输入注册信息**：
   - 实时验证邮箱/手机号格式
   - 密码强度检查（至少8位，包含字母和数字）
   - 密码与确认密码一致性检查
3. **同意用户协议**：必须勾选才能注册
4. **点击注册按钮**：
   - 表单验证通过：提交注册请求
   - 表单验证失败：显示错误提示
5. **注册成功**：
   - 显示成功提示
   - 自动登录并跳转到首页/仪表盘
   - 或提示用户前往邮箱/手机验证

### 4.3 第三方登录流程

1. **用户选择第三方登录**：点击对应的第三方登录按钮
2. **跳转授权页面**：打开第三方应用或网页授权界面
3. **用户授权**：在第三方平台确认授权
4. **返回应用**：授权成功后返回应用
5. **登录/注册处理**：
   - 首次登录：自动创建账号并登录
   - 已有账号：直接登录

### 4.4 关键交互细节

#### 4.4.1 表单验证
- **实时验证**：用户输入时立即验证格式和有效性
- **错误提示**：
  - 位置：输入框下方，红色文字
  - 内容：明确说明错误原因（如"邮箱格式不正确"、"密码长度不足"）
- **成功提示**：输入框右侧显示绿色对勾图标

#### 4.4.2 密码安全
- **密码隐藏**：默认隐藏密码，显示圆点
- **显示/隐藏切换**：点击眼睛图标可切换密码显示状态
- **密码强度指示器**（注册时）：
  - 弱：红色，长度不足或复杂度不够
  - 中：黄色，基本符合要求
  - 强：绿色，复杂度高

#### 4.4.3 页面切换
- **登录/注册切换**：点击切换链接时，表单区域平滑过渡（0.3秒）
- **加载状态**：提交表单时，按钮显示加载动画（旋转图标）
- **错误状态**：登录/注册失败时，显示错误提示弹窗或内嵌提示

#### 4.4.4 忘记密码流程
1. **用户点击"忘记密码"**：跳转到忘记密码页面
2. **输入邮箱/手机号**：用户输入注册时使用的邮箱或手机号
3. **发送验证码**：系统发送验证码到用户邮箱/手机
4. **验证身份**：用户输入收到的验证码
5. **重置密码**：验证通过后，用户设置新密码
6. **完成重置**：提示密码重置成功，引导用户登录

## 5. 响应式设计

### 5.1 移动端设计（< 768px）

- **布局**：垂直居中布局，表单宽度100%（减去左右边距32px）
- **组件大小**：
  - Logo：48px × 48px
  - 输入框高度：48px
  - 按钮高度：48px
  - 第三方登录按钮高度：44px
- **导航**：无额外导航，专注于登录/注册功能
- **插图**：简化的移动端友好插图，位于Logo和表单之间

### 5.2 平板设计（768px - 1024px）

- **布局**：垂直居中布局，表单最大宽度480px
- **组件大小**：
  - Logo：56px × 56px
  - 输入框高度：48px
  - 按钮高度：48px
- **插图**：更大的品牌插图，增强视觉效果

### 5.3 Web端设计（> 1024px）

- **布局**：水平分栏布局，左侧品牌区域，右侧表单区域
- **组件大小**：
  - Logo：64px × 64px
  - 输入框高度：48px
  - 按钮高度：48px
- **插图**：完整的品牌插图，位于左侧品牌区域中央
- **额外元素**：背景装饰元素，提升页面质感

## 6. 设计规范

### 6.1 色彩规范
- 遵循品牌色彩方案，确保视觉一致性
- 文本与背景对比度符合WCAG AA标准
- 按钮和交互元素颜色鲜明，易于识别

### 6.2 间距规范
- 元素间距基于8pt网格系统
- Logo到口号：16px
- 口号到插图：24px
- 插图到表单：32px
- 表单内部元素间距：16px
- 表单到第三方登录：24px
- 第三方登录按钮间距：12px
- 第三方登录到切换区域：24px

### 6.3 字体规范
- 使用Inter字体家族
- 保持字体层级清晰
- 按钮文字使用500 weight，增强可读性

### 6.4 可访问性规范
- 所有输入框都有清晰的标签
- 支持键盘导航（Tab键顺序合理）
- 屏幕阅读器友好
- 高对比度设计，适合视觉障碍用户

## 8. 测试要点

1. **表单验证**：
   - 邮箱/手机号格式验证
   - 密码强度验证
   - 密码与确认密码一致性验证
   - 必填项验证

2. **交互体验**：
   - 登录/注册切换流畅性
   - 按钮点击反馈
   - 加载状态显示
   - 错误提示清晰度

3. **兼容性**：
   - 移动端浏览器兼容性
   - Web端浏览器兼容性
   - iOS/Android平台差异

4. **安全性**：
   - 密码加密传输
   - 防止SQL注入
   - 防止暴力破解
   - 第三方登录授权安全

5. **可访问性**：
   - 键盘导航支持
   - 屏幕阅读器支持
   - 高对比度模式支持
