# UI设计-写作模块

## 1. 设计目标

写作模块的UI设计旨在提供一个专注、高效的写作环境，同时确保用户能够方便地获取AI反馈和学习建议。设计遵循以下原则：

- **专注写作体验**：提供简洁无干扰的写作区域，帮助用户集中注意力
- **即时反馈机制**：实时显示字数统计和基本语法检查
- **清晰的任务指导**：明确展示写作题目和要求
- **结构化的评分反馈**：以可视化方式展示AI评分结果和改进建议
- **响应式适配**：在不同设备上提供一致的写作体验

## 2. 页面结构

### 2.1 核心功能模块

| 功能模块 | 描述 |
| --------- | ------ |
| 左侧边栏 | 显示用户信息、学习统计概览、核心功能导航 |
| 顶部工具栏 | 显示面包屑导航、全局搜索、通知中心、用户头像菜单、设置按钮 |
| 题目展示区 | 显示写作题目、类型（Task 1/Task 2）、要求和时间限制 |
| 写作输入区 | 提供富文本编辑器，支持基本格式和语法检查 |
| 字数统计 | 实时显示当前字数和目标字数 |
| 工具栏 | 提供保存、提交、格式调整等功能按钮 |
| AI反馈区 | 展示语法错误、词汇建议、评分和改进意见 |
| 历史记录 | 显示用户过往写作练习和评分记录 |

### 3.3 组件样式

#### 3.3.1 写作输入框

- **宽度**：
  - Web端：100%（主内容区内），最大宽度1000px
  - 平板：100% - 48px
  - 移动端：100% - 32px
- **高度**：
  - Web端：550px
  - 平板：450px
  - 移动端：350px
- **内边距**：24px（Web端），16px（移动端）
- **边框**：1px solid #E5E7EB，圆角 12px
- **背景色**：#FFFFFF
- **阴影**：
  - 常规状态：0 4px 12px rgba(0, 0, 0, 0.06)
  - 聚焦状态：0 6px 16px rgba(245, 158, 11, 0.15)，边框颜色变为 #F59E0B
- **字体**：Inter-Regular，16px，行高 26px

#### 3.3.2 字数统计组件

- 显示当前字数/目标字数
- 字体：Inter-Medium，14px，行高 20px
- **颜色**：
  - 常规状态：#F59E0B
  - 达到 80% 目标时：#10B981（成功色）
  - 达到 100% 目标时：#059669（成功色深色）
- **动画效果**：
  - 当时间剩余不足 10 分钟时，添加脉冲警告动画效果
  - 字数增加时，添加轻微的缩放动画

#### 3.3.3 AI反馈卡片

采用标准卡片样式，符合UI设计风格指南：

- **背景色**：#FFFFFF
- **内边距**：24px
- **边框**：1px solid #E5E7EB，圆角 12px
- **阴影**：
  - 常规状态：0 4px 12px rgba(0, 0, 0, 0.06)
  - 悬停状态：0 8px 24px rgba(0, 0, 0, 0.12)
- **错误提示**：使用红色波浪线标记文本中的语法错误，点击可查看详细解释
- **词汇建议**：使用 #FEF3C7 背景色高亮显示可替换的词汇，鼠标悬停显示建议词汇
- **评分卡片**：使用更大的内边距（32px）和更强的阴影效果，突出显示评分结果

#### 3.3.4 按钮组件

- **主要按钮**（提交练习）：
  - 样式：圆角 10px，填充主色调 #F59E0B，白色文字
  - 尺寸：高度48px，文字16px，最小宽度140px
  - 交互效果：
    - 悬停：背景色加深至 #D97706，阴影增强（0 4px 12px rgba(245, 158, 11, 0.3)）
    - 点击：轻微下沉效果（scale: 0.98），背景色变为 #D97706
    - 聚焦：添加2px橙色外发光效果

- **次要按钮**（保存草稿、格式化）：
  - 样式：圆角 10px，描边主色调 #F59E0B，主色调文字，透明背景
  - 尺寸：高度44px，文字15px，最小宽度120px
  - 交互效果：
    - 悬停：轻微填充主色调（背景色 #FEF3C7），阴影增强
    - 点击：轻微下沉效果，描边颜色加深

## 4. 交互设计

### 4.1 核心交互流程

#### 4.1.1 写作练习流程

```
1. 用户从左侧边栏导航进入写作模块
2. 顶部工具栏显示当前位置（面包屑导航）
3. 用户选择写作任务类型（Task 1/Task 2）
4. 系统以卡片形式展示题目和要求，带有平滑的入场动画
5. 用户开始写作，实时显示字数统计和时间倒计时
6. AI实时提供语法检查和词汇建议，带有轻微的动画提示
7. 用户可保存草稿（自动保存功能）或提交练习
8. 提交时显示加载动画，完成后平滑过渡到评分报告页面
9. 系统生成详细的评分报告，带有可视化的分数展示
```

#### 4.1.2 语法检查交互

- **实时检查**：文本输入时自动进行语法检查，延迟500ms避免频繁检查
- **错误标记**：
  - 语法错误：红色波浪线标记，鼠标悬停显示错误原因
  - 词汇建议：#FEF3C7 背景色高亮，鼠标悬停显示可替换词汇列表
- **交互反馈**：
  - 点击错误位置，显示详细的错误原因和修正建议卡片
  - 提供一键修正功能，点击后有平滑的替换动画
  - 修正后，错误标记消失，显示轻微的成功动画

#### 4.1.3 卡片交互效果

- **卡片悬停**：所有卡片（题目展示区、AI反馈区等）悬停时轻微上浮（transform: translateY(-2px)）并增强阴影
- **平滑过渡**：卡片内容变化时使用淡入淡出动画
- **进度反馈**：写作过程中，字数统计和时间倒计时有数字变化动画

#### 4.1.4 导航交互

- **左侧边栏**：
  - 当前选中的导航项高亮显示，使用 #F59E0B 主色调
  - 导航项悬停时有背景色变化（#FEF3C7）和轻微的缩放效果
  - 支持折叠功能，点击折叠按钮有平滑的宽度变化动画

- **顶部工具栏**：
  - 通知中心有新消息时显示红点提示和轻微的脉冲动画
  - 用户头像悬停时显示下拉菜单，带有淡入动画
  - 面包屑导航点击时显示历史路径，带有平滑的展开动画

### 4.2 表单验证

| 表单元素 | 验证规则 | 错误提示 | 视觉反馈 |
| ---------- | ---------- | ---------- | ---------- |
| 写作内容 | 不能为空 | "请输入你的作文内容" | 输入框边框变为 #EF4444，显示错误提示卡片，带有淡入动画 |
| 字数限制 | Task 1: ≥150词<br>Task 2: ≥250词 | "作文字数不足要求" | 字数统计变为 #EF4444，提交按钮禁用并显示提示信息 |
| 时间限制 | 40分钟内完成 | "时间已到，请尽快提交" | 时间显示变为 #EF4444，带有脉冲警告动画 |

**验证时机**：

- 实时验证：字数和时间限制在输入过程中实时检查
- 提交验证：提交时进行最终验证，确保所有要求都已满足

**错误提示样式**：

- 错误提示卡片：圆角 10px，背景色 #FEE2E2，边框 1px solid #EF4444，内边距 12px
- 提示文字：Inter-Medium，14px，颜色 #DC2626
- 动画效果：淡入动画（opacity: 0 → 1，transform: translateY(-10px) → 0）

## 5. 响应式设计

### 5.1 设计原则（Web优先）

- **Web优先设计**：优先保证桌面端（1024px+）的最佳体验
- **渐进式增强**：在移动设备上简化但不牺牲核心功能
- **断点设置**：
  - Web端：1024px+（完整功能）
  - 平板：768-1023px（简化布局）
  - 移动端：320-767px（垂直布局）

### 5.2 Web端适配（1024px+）

- 完整的三栏布局（左侧边栏+顶部工具栏+主内容区）
- 左侧边栏固定宽度280px，包含完整导航和用户信息
- 顶部工具栏高度64px，包含完整的全局功能
- 主内容区采用12列网格系统，最大宽度1200px，居中显示
- 题目展示区和AI反馈区并排显示（左右两列）
- 写作输入区高度550px，提供最佳写作体验
- 实时显示完整的AI反馈和语法检查结果

### 5.3 平板适配（768-1023px）

- 左侧边栏可折叠为图标模式（宽度80px）或转为顶部导航
- 顶部工具栏保留核心功能（面包屑、搜索、用户菜单）
- 主内容区采用8列网格系统，宽度100%
- 题目展示区和AI反馈区垂直堆叠
- 写作输入区高度450px
- 简化部分次要功能，保持核心写作体验

### 5.4 移动端适配（320-767px）

- 左侧边栏转为底部导航栏（5个核心功能）
- 顶部状态栏简化为标题、返回按钮和主要操作
- 主内容区采用4列网格系统，宽度100%
- 所有内容垂直堆叠，确保良好的滚动体验
- 写作输入区高度350px，适应小屏幕
- 简化工具栏，只保留保存和提交功能
- AI反馈区可折叠，点击展开查看详细建议

### 5.5 响应式组件调整

| 组件 | Web端 | 平板 | 移动端 |
| ------ | ------ | ------ | ------ |
| 左侧边栏 | 固定280px | 可折叠 | 底部导航栏 |
| 顶部工具栏 | 64px高度 | 64px高度 | 48px高度 |
| 写作输入区高度 | 550px | 450px | 350px |
| 输入框内边距 | 24px | 20px | 16px |
| 卡片圆角 | 12px | 10px | 8px |
| 按钮尺寸 | 48px高度 | 44px高度 | 40px高度 |

## 8. 设计规范

### 8.1 基础规范

- **8pt网格系统**：所有元素的尺寸、间距和边距均遵循8pt网格系统，确保视觉对齐和一致性
- **色彩方案**：严格使用橙色系主色调（#F59E0B）和UI设计风格指南中定义的色彩变量
- **字体系统**：统一使用Inter字体，建立清晰的字体层级结构
- **响应式设计**：遵循Web优先原则，确保桌面端（1024px+）提供最佳体验

### 8.2 组件规范

- **卡片设计**：
  - 圆角：12px
  - 阴影：0 4px 12px rgba(0, 0, 0, 0.06)（常规），0 8px 24px rgba(0, 0, 0, 0.12)（悬停）
  - 内边距：24px（Web端），16px（移动端）
  - 边框：1px solid #E5E7EB

- **按钮设计**：
  - 主要按钮：圆角10px，高度48px，填充主色调
  - 次要按钮：圆角10px，高度44px，描边主色调
  - 交互效果：悬停时背景色变化，阴影增强，轻微上浮

- **输入框设计**：
  - 圆角：12px
  - 边框：1px solid #E5E7EB
  - 内边距：24px（Web端），16px（移动端）
  - 聚焦效果：边框变为 #F59E0B，阴影增强

### 8.3 交互规范

- **反馈机制**：所有交互操作都有明确的视觉反馈（颜色变化、动画、提示等）
- **平滑过渡**：页面切换和内容变化时使用淡入淡出动画
- **悬停效果**：可交互元素悬停时有状态变化
- **加载状态**：提交、保存等耗时操作显示加载动画

### 8.4 可访问性规范

- **颜色对比度**：确保文本与背景的对比度符合WCAG AA标准
- **键盘导航**：支持全键盘操作
- **屏幕阅读器**：提供适当的ARIA标签和语义化HTML
- **字体大小**：支持文本放大功能

### 8.5 性能规范

- **实时检查优化**：语法检查采用增量检查，延迟500ms避免频繁请求
- **自动保存**：采用节流机制，每30秒自动保存一次
- **图表懒加载**：图表和图片采用懒加载技术
- **动画性能**：所有动画使用CSS transform和opacity属性，确保流畅性能

## 9. 性能优化

### 9.1 前端性能优化

- **实时语法检查优化**：
  - 采用增量检查，只检查最近修改的文本片段
  - 延迟500ms执行检查，避免频繁请求
  - 限制检查频率，每2秒最多检查一次

- **自动保存机制**：
  - 采用节流机制，每30秒自动保存一次
  - 只在内容变化时触发保存
  - 保存时使用防抖处理，避免连续请求

- **资源加载优化**：
  - 图表和图片采用懒加载技术
  - 编辑器资源按需加载
  - AI反馈组件异步渲染

- **动画性能**：
  - 所有动画使用CSS transform和opacity属性
  - 避免使用expensive properties (如box-shadow、border-radius)的动画
  - 使用requestAnimationFrame确保流畅性能

### 9.2 后端性能优化

- **评分报告生成**：采用异步处理，避免阻塞主线程
- **AI模型调用**：使用缓存机制，减少重复请求
- **数据库优化**：写作内容和反馈数据分离存储，提高查询效率

## 10. 无障碍设计

### 10.1 核心无障碍特性

- **键盘导航**：
  - 支持全键盘操作，包括Tab导航、Enter选择、Esc取消
  - 导航顺序符合视觉层次
  - 可访问的焦点指示器

- **屏幕阅读器兼容**：
  - 提供适当的ARIA标签和语义化HTML
  - 确保所有交互元素都有可访问的名称
  - 动态内容变化时提供适当的通知

- **颜色对比度**：
  - 确保文本与背景的对比度符合WCAG AA标准（4.5:1）
  - 重要信息的对比度达到WCAG AAA标准（7:1）
  - 避免仅通过颜色传达信息

- **文本放大**：
  - 支持浏览器文本放大功能（200%）
  - 放大后布局保持稳定，内容不重叠

- **错误提示**：
  - 提供清晰的错误提示信息
  - 错误信息与相关字段关联
  - 支持屏幕阅读器朗读错误信息

### 10.2 写作模块特有无障碍设计

- **编辑器可访问性**：
  - 支持键盘快捷操作
  - 提供行号和段落导航
  - 语法错误和词汇建议可通过键盘访问

- **图表无障碍**：
  - 为图表提供文本描述
  - 支持屏幕阅读器读取图表数据
  - 提供图表数据的表格版本

- **时间管理**：
  - 提供声音提醒功能
  - 时间倒计时可通过键盘访问
  - 支持自定义时间提醒设置

以上设计确保了写作模块具有良好的用户体验、高效的写作环境和有价值的AI反馈，帮助用户有效提升IELTS写作能力。
