# 听力模块 UI设计

## 1. 设计目标

- **核心目标**：提供沉浸式的听力练习体验，支持多种题型和难度级别
- **用户体验**：简化操作流程，专注听力内容，提供及时反馈和详细解析
- **功能完整性**：支持音频播放控制、题目作答、进度保存、错题记录等功能
- **学习效果**：通过可视化进度和个性化推荐提升学习效率
- **视觉一致性**：遵循品牌设计语言，保持与其他页面的视觉统一

## 2. 页面结构

### 2.1 核心组件

- **顶部导航栏**：返回、题目信息、设置等
- **音频播放控制**：播放/暂停、音量调节、进度条、语速调节
- **题目展示区**：题目文本、选项（根据题型变化）
- **作答区域**：答案输入/选择控件
- **辅助功能**：原文查看、重点词汇、笔记功能
- **操作按钮区**：上一题、下一题、提交答案、查看解析
- **进度追踪**：题目导航、完成状态
- **学习数据**：得分统计、错题分析
- **底部导航**：移动端核心功能快速切换

## 3. 视觉设计

### 3.1 色彩应用

- **主色调**：`#4A6CF7`（蓝色）- 用于主要按钮、音频控制、重点标记
- **辅助色**：`#F7B955`（橙色）- 用于警告、提醒和次要强调
- **成功色**：`#50CD89`（绿色）- 用于正确答案、完成状态
- **危险色**：`#F1416C`（红色）- 用于错误答案、警告提示
- **中性色**：`#F8F9FA`（背景）、`#86909C`（次要文本）、`#212529`（主要文本）
- **题目背景**：`#FFFFFF`（白色）- 确保题目文本清晰可读
- **选项背景**：`#F8F9FA`（浅灰）- 未选择状态
- **选中选项**：`#E3E7FF`（浅蓝色）- 选中状态

### 3.2 排版设计

- **题目类型**：Inter 600, 16px, `#4A6CF7`
- **题目文本**：Inter 500, 18px, `#212529`（移动端）/ 20px（网页端）
- **选项文本**：Inter 400, 16px, `#495057`（移动端）/ 18px（网页端）
- **辅助文字**：Inter 400, 14px, `#86909C`
- **按钮文本**：Inter 500, 16px, `#FFFFFF`（主要按钮）/ `#4A6CF7`（次要按钮）

### 3.3 组件设计

#### 3.3.1 顶部导航栏

- **高度**：60px
- **背景色**：`#FFFFFF`
- **包含元素**：返回图标（24px）、题目信息（题型、题号/总题数）、设置图标（24px）
- **阴影**：1px 2px 8px rgba(0, 0, 0, 0.08)

#### 3.3.2 音频播放控制

- **高度**：80px
- **背景色**：`#FFFFFF`
- **播放/暂停按钮**：圆形（48px），背景色 `#4A6CF7`，图标颜色 `#FFFFFF`
- **进度条**：高度 4px，背景色 `#E9ECEF`，进度颜色 `#4A6CF7`
- **音量控制**：音量图标（20px）+ 滑块
- **语速调节**：下拉菜单，默认正常语速
- **边框**：底部 1px solid `#E9ECEF`

#### 3.3.3 题目展示区

- **背景色**：`#FFFFFF`
- **内边距**：20px
- **题目类型标签**：圆角矩形（8px），背景色 `#E3E7FF`，文字颜色 `#4A6CF7`，内边距 8px 16px
- **题目文本**：行高 1.6，确保长文本可读性
- **图片展示**：如果有配图，居中显示，最大宽度 100%

#### 3.3.4 作答区域

根据题型不同，作答区域会有相应变化：

- **选择题**：
  - 选项容器：白色背景，圆角 8px，边框 1px solid `#E9ECEF`，内边距 16px
  - 选中状态：边框颜色 `#4A6CF7`，背景色 `#E3E7FF`
  - 正确答案：边框颜色 `#50CD89`，背景色 `#E8FFF3`
  - 错误答案：边框颜色 `#F1416C`，背景色 `#FFF0F3`

- **填空题**：
  - 输入框：高度 48px，白色背景，圆角 8px，边框 1px solid `#E9ECEF`
  - 聚焦状态：边框颜色 `#4A6CF7`，添加轻微阴影
  - 错误状态：边框颜色 `#F1416C`

- **匹配题**：
  - 两列布局：左侧选项，右侧匹配目标
  - 拖动控件：支持拖拽匹配
  - 连接线：可视化匹配关系

#### 3.3.5 辅助功能区

- **高度**：60px
- **背景色**：`#FFFFFF`
- **按钮样式**：圆角 8px，背景色 `#F8F9FA`，文字颜色 `#495057`，内边距 12px 16px
- **图标尺寸**：20px
- **边框**：1px solid `#E9ECEF`

#### 3.3.6 操作按钮区

- **次要按钮**：背景色 `#F8F9FA`，文字颜色 `#495057`，圆角 8px，高度 48px，内边距 20px

#### 3.3.7 进度追踪

#### 3.3.8 学习数据区

- **卡片样式**：白色背景，圆角 12px，阴影 0px 4px 12px rgba(0, 0, 0, 0.06)
- **数据项**：图标（24px）+ 数值 + 描述
- **间距**：16px

#### 3.3.9 底部导航栏（移动端）

与首页/仪表盘保持一致：

- **高度**：60px
- **背景色**：`#FFFFFF`
- **阴影**：-1px -2px 8px rgba(0, 0, 0, 0.06)
- **图标尺寸**：24px
- **激活状态**：图标和文字颜色 `#4A6CF7`

## 3. 交互设计

### 3.1 用户流程

1. **进入模块**：从首页点击听力模块进入
2. **选择练习**：选择题型、难度、套题等
3. **开始练习**：进入题目页面，播放音频
4. **作答**：根据题目要求选择/输入答案
5. **音频控制**：根据需要调节播放、音量、语速
6. **辅助功能**：使用原文查看、重点词汇等功能
7. **导航**：通过上一题/下一题或进度点切换题目
8. **提交答案**：完成所有题目后提交
9. **查看结果**：查看得分和详细解析
10. **错题记录**：系统自动记录错题，用于复习

### 3.2 微交互设计

- **音频播放**：
  - 播放/暂停：图标平滑切换，播放时有波形动画
  - 进度条：拖动时实时预览，松手后跳转到对应位置
  - 音量调节：滑块拖动时显示音量数值提示

- **题目作答**：
  - 选项选择：点击时有轻微缩放效果，选中状态即时反馈
  - 填空题输入：实时验证输入格式，错误时有提示
  - 匹配题拖拽：拖拽过程中有视觉引导，释放时有匹配动画

- **页面导航**：
  - 上一题/下一题：平滑过渡动画，保持音频播放状态
  - 进度点点击：直接跳转到对应题目，更新当前状态

- **反馈机制**：
  - 答案正确：显示绿色对勾，轻微震动反馈
  - 答案错误：显示红色叉号，错误提示文字
  - 提交完成：进度条动画，得分统计渐入

### 3.3 特殊场景处理

- **网络中断**：提示网络状态，自动保存当前进度
- **音频加载失败**：显示重试按钮，提供文字原文
- **作答超时**：自动提交当前答案，提示超时信息
- **退出练习**：提示是否保存进度，确认后退出

## 4. 题型适配设计

### 4.1 选择题

- **布局**：垂直排列选项，每个选项占一行
- **选择控件**：圆形单选按钮或方形复选框
- **作答反馈**：选中状态即时显示

### 4.2 填空题

- **输入框**：下划线或框式输入框
- **字数限制**：实时显示已输入字数
- **自动补全**：提供可能的答案建议

### 4.3 匹配题

- **两列布局**：左侧为待匹配项，右侧为目标项
- **交互方式**：支持点击匹配或拖拽匹配
- **可视化**：匹配成功后显示连接线

### 4.4 地图题

- **地图展示**：可缩放的地图界面
- **标记功能**：支持在地图上标记位置
- **选项**：根据地图位置选择答案

## 5. 响应式设计

### 5.1 移动端（320px - 767px）

- **布局**：单列流式布局，确保内容垂直排列
- **音频控制**：简化控件，保留核心功能
- **题目文本**：自适应字号，确保可读性
- **作答区域**：优化触控体验，增大点击区域
- **辅助功能**：折叠显示，点击展开

### 5.2 平板端（768px - 1023px）

- **布局**：部分模块采用双列布局（如题目和选项）
- **音频控制**：完整控件显示，增加语速调节
- **作答区域**：优化空间利用，提升操作效率
- **辅助功能**：横向排列，方便快速切换

### 5.3 网页端（1024px +）

- **布局**：左侧固定导航，右侧内容区采用模块化布局
- **音频控制**：完整功能展示，支持更多自定义选项
- **作答区域**：更大的操作空间，支持复杂交互
- **学习数据**：多维度数据可视化展示

## 9. 设计迭代说明

本设计基于用户需求和听力学习场景进行了多次迭代，重点关注：

1. **沉浸式体验**：简化界面元素，让用户专注于听力内容
2. **操作便捷性**：音频控制和作答操作触手可及
3. **题型适配**：灵活支持多种听力题型
4. **反馈及时性**：提供即时的作答反馈和详细解析
5. **进度追踪**：清晰展示学习进度和完成情况

后续将根据用户反馈和使用数据进行进一步优化和迭代。
