# 英语学习智能助手 - API测试接口文档

## 1. 认证模块 (auth.py)

### 1.1 用户注册
- **路径**: `/auth/register`
- **方法**: `POST`
- **描述**: 用户注册新账号
- **请求体**:
  ```json
  {
    "email": "string",
    "password": "string",
    "username": "string"
  }
  ```
- **响应**:
  ```json
  {
    "access_token": "string",
    "token_type": "bearer",
    "user": {
      "id": "string",
      "email": "string",
      "username": "string"
    }
  }
  ```

### 1.2 用户登录
- **路径**: `/auth/login`
- **方法**: `POST`
- **描述**: 用户登录获取访问令牌
- **请求体**:
  ```json
  {
    "email": "string",
    "password": "string"
  }
  ```
- **响应**:
  ```json
  {
    "access_token": "string",
    "token_type": "bearer",
    "user": {
      "id": "string",
      "email": "string",
      "username": "string"
    }
  }
  ```

### 1.3 获取当前用户信息
- **路径**: `/auth/me`
- **方法**: `GET`
- **描述**: 获取当前登录用户的信息
- **请求头**:
  - `Authorization`: `Bearer {token}`
- **响应**:
  ```json
  {
    "id": "string",
    "email": "string",
    "username": "string",
    "created_at": "2023-01-01T00:00:00"
  }
  ```

    "reading": 6.5,

## 3. 口语练习模块 (speaking.py)

### 3.1 创建口语练习会话
- **路径**: `/speaking/session`
- **方法**: `POST`
- **描述**: 创建新的口语练习会话
- **请求头**:
  - `Authorization`: `Bearer {token}`
- **请求体**:
  ```json
  {
    "topic": "string"
  }
  ```
- **响应**:
  ```json
  {
    "id": "string",
    "user_id": "string",
    "topic": "string",
    "status": "created",
    "created_at": "2023-01-01T00:00:00",
    "started_at": null,
    "finished_at": null
  }
  ```

### 3.2 获取口语练习会话
- **路径**: `/speaking/session/{session_id}`
- **方法**: `GET`
- **描述**: 获取口语练习会话详情
- **请求头**:
  - `Authorization`: `Bearer {token}`
- **路径参数**:
  - `session_id`: 会话ID
- **响应**:
  ```json
  {
    "id": "string",
    "user_id": "string",
    "topic": "string",
    "status": "in_progress",
    "created_at": "2023-01-01T00:00:00",
    "started_at": "2023-01-01T00:05:00",
    "finished_at": null,
    "parts": [
      {
        "id": "string",
        "part": 1,
        "status": "completed",
        "transcript": "string",
        "audio_url": "string",
        "created_at": "2023-01-01T00:05:00",
        "finished_at": "2023-01-01T00:10:00"
      }
    ]
  }
  ```

### 3.3 开始口语练习部分
- **路径**: `/speaking/session/{session_id}/part`
- **方法**: `POST`
- **描述**: 开始口语练习的某个部分
- **请求头**:
  - `Authorization`: `Bearer {token}`
- **路径参数**:
  - `session_id`: 会话ID
- **请求体**:
  ```json
  {
    "part": 1
  }
  ```
- **响应**:
  ```json
  {
    "id": "string",
    "part": 1,
    "status": "in_progress",
    "transcript": null,
    "audio_url": null,
    "created_at": "2023-01-01T00:05:00",
    "finished_at": null
  }
  ```

### 3.4 提交口语练习音频
- **路径**: `/speaking/session/{session_id}/part/{part_id}/audio`
- **方法**: `POST`
- **描述**: 提交口语练习的音频文件
- **请求头**:
  - `Authorization`: `Bearer {token}`
- **路径参数**:
  - `session_id`: 会话ID
  - `part_id`: 部分ID
- **请求体**:
  - `multipart/form-data`
  - `audio`: 音频文件
  - `transcript`: 文本转录
- **响应**:
  ```json
  {
    "id": "string",
    "part": 1,
    "status": "completed",
    "transcript": "string",
    "audio_url": "string",
    "created_at": "2023-01-01T00:05:00",
    "finished_at": "2023-01-01T00:10:00"
  }
  ```

### 3.5 完成口语练习会话

- **描述**: 完成口语练习会话

## 10. 通用信息

### 10.1 API版本
- 当前版本: 1.0
- 基础URL: `http://localhost:8000`

### 10.2 认证方式
- 使用JWT Bearer Token
- 所有需要认证的接口都需要在请求头中包含: `Authorization: Bearer {token}`

### 10.3 错误响应格式
```json
{
  "detail": "string"
}
```

### 10.4 状态码
- 200: 成功
- 201: 创建成功
- 400: 请求参数错误
- 401: 未授权
- 404: 资源不存在
- 500: 服务器内部错误
